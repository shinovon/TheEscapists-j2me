# Platform builds

Preprocessed builds as defined by `.mtj` and `deployed/release.sh`

- **S40** - Optimized for S40v5+, Sony Ericsson
- **S60** - Optimized for S60v3, S60v2
- **S60_scaled** - Upscaled 320x240 image with virtual keyboard for S60v5, S^3
- **E6_E7** - Upscaled 320x240 image without virtual keyboard for Nokia E6, E7
- **Minimum** - Reduced build for devices with low memory or no M3G support
